# 김비서 (KimBiseo)

내 PC 안에서 돌아가는 **말로 부르는 비서**와 **바탕화면 캐릭터 펫**입니다.
"김비서" 하고 부르거나 창에 글을 쓰면 대답하고, 바탕화면의 펫이 말에 맞춰 입을 움직이고 표정·동작을 합니다.

이 프로젝트는 하이라이프PC 가 만들었습니다.

## 무엇을 하나요

- **대화**: 말로 묻고 말로 듣습니다. 날씨·검색·가격 조사·계산·프로그램 열기·기억하기·메모 적기 같은 기본 도구가 들어 있습니다.
  "RTX 5090 가격 검색해서 메모장에 정리해 줘"처럼 여러 단계 부탁도 차례로 합니다. 메모는 김비서가 직접 띄우는 **김비서 메모** 창에만 적고
  (윈도우 메모장은 저절로 켜지 않음), Ctrl+S·저장 단추로 `문서\김비서 메모\` 에 저장합니다.
- **두뇌**: 이 PC 에 클로드 코드·Codex(ChatGPT)가 본인 계정으로 로그인돼 있으면 그 구독을 그대로 씁니다(김비서가 그 프로그램을 직접 부름 — 계정·토큰은 김비서가 보지 않음). 없으면 내 PC 에서 도는 Gemma 4 무검열 판(보통 E4B · 가벼운 E2B 중 고름, llama.cpp, 원 배포처에서 직접 받음). 설정에서 내 로컬 AI 주소(OpenAI 호환)·API 열쇠(GPT·클로드)로도 바꿀 수 있습니다.
- **귀·목소리**: 받아쓰기는 whisper, 목소리는 Qwen3-TTS 김비서 목소리(그래픽 메모리 6GB 미만·모자랄 때는 윈도우 기본 음성). 김비서(여)·김비서(남) 두 목소리가 들어 있고, 펫이 입은 옷에 맞춰 저절로 바뀝니다(설정에서 직접 고를 수도 있음).
  조용할 때 잡음·숨소리를 '고맙습니다'·'안녕' 같은 말로 잘못 받아쓰는 것은 **말소리 문**(0.1.17~)이 막습니다 — 사람 말소리가 충분한 조각만 받아쓰고, 짧고 약한 조각의 인사·감사 한마디는 버립니다(설정 파일 `귀.말소리_문`).
- **펫**: 바탕화면 캐릭터 — 김비서(여)·김비서(남). 옷(꾸러미)은 처음 화면에서 동의하면 고른 캐릭터의 옷을 받고, 다른 옷은 펫 메뉴 **옷 더 받기** 에서 원하는 것만 골라 받습니다(옷 목록 = [kimbiseo-outfits](https://github.com/sinhs0301-prog/kimbiseo-outfits)).
- **말싸움(토론)**(0.1.18~): "말싸움 하자"·"토론하자"라고 하면 다른 AI와 정보는 빼고 주장만으로 붙습니다. 켜진 동안에는 이름·주소·전화·기억 같은 개인 정보와 메일·파일·PC 조작 도구를 두뇌에 넘기지 않고 검색·날씨·계산만 씁니다. "말싸움 그만"·"평소로"로 끄고, 30분 동안 말이 없으면 저절로 꺼집니다. 기본은 반말·센 말·비꼬기·도발이고, 설정 → 대화의 **성인 말싸움(19+)**(PC 판)을 켜면 실제 욕설·막말·과장된 위협 드립·섹드립까지 허용합니다.
- **통역**(0.1.15~): "태국어 통역해 줘"·"통역해 줘"(자동)라고 하면 한국어 ↔ 13개 언어(영어·태국어·일본어·중국어·인도네시아어·베트남어·독일어·그리스어·터키어·러시아어·프랑스어·스페인어·이탈리아어)를 옮겨 줍니다.
  상대가 말한 언어를 알아듣고, 통역 중 말은 **번역만** 합니다(김비서에게 하는 부탁으로 받지 않음). "통역 그만"·화면 '끄기'로 끄고, 10분 동안 말이 없으면 저절로 꺼집니다.
  번역은 지금 두뇌(이 PC 의 Gemma 등)로 하고, 숫자·금액은 원문 숫자를 지키며, 상대가 말한 외국 돈은 원화로 어림해 "(약 14,000원)"으로 덧붙입니다(환율 하루 한 번).
  외국어는 **원어민 목소리**(설정 → 통역 '통역 목소리 받기', 약 800MB — Kokoro·Piper·태국어 MrJMThaiTTS)로 읽고, 인도네시아어·베트남어는 상업용으로 쓸 수 있는 목소리가 없어 글자로 보여 줍니다.
  태국어 목소리(0.1.17~)는 가중치가 Apache-2.0 이지만 학습 자료가 비상업 모델로 만든 합성음이라 상업 사용은 회색입니다 — [THIRD_PARTY_LICENSES](THIRD_PARTY_LICENSES/README.md).
- **폰으로 쓰기**(0.1.16~, 선택, 기본 꺼짐): 폰에 '김비서' 앱을 깔고 이 PC 와 연결하면, 폰으로 말해도 이 PC 의 김비서가 대답합니다 — 아래 '폰으로 쓰기'.
- **내 목소리 등록**(0.1.16~, 선택, 기본 꺼짐): 문장 몇 개를 읽어 두면 '등록한 목소리만 명령 받기'를 켤 수 있습니다(TV·다른 사람 말에 대답하지 않게) — 아래 '내 목소리 등록'.
- **내 마음대로 바꾸기**(설정): 말투(자동·존댓말·편한 존댓말·반말)·답 길이·성격 설명, 목소리 세부(말 빠르기·억양 변화·문장 사이 쉼 — '기본값으로' 단추),
  펫 크기(50~200%), 김비서 창 크기(가장자리를 끌어 조절 · 크기와 자리를 기억). 숫자·날짜·단위는 화면 글은 그대로 두고 **읽을 때만** 한국어로 바꿔 읽습니다
  ("12개" → 열두 개, "3시 30분" → 세 시 삼십 분, "0.1.12" → 영 점 일 점 십이).
- **모니터가 여러 대여도**: 모니터마다 배율(100%·125%·150%)이 달라도 창을 옮길 때 좌표가 틀어지지 않고, 펫은 어느 화면의 어디에 있었는지를 기억합니다.
  모니터를 빼면 보이는 화면으로 옮겨 오고, 다시 꽂으면 원래 자리로 돌아갑니다.
- **내 API 열쇠로**: 두뇌에 **OpenAI 호환 API** 를 고르면 OpenAI 방식 주소를 주는 바깥 AI 서비스를 내 API 열쇠로 쓸 수 있습니다(주소·모델·열쇠 · 연결 시험).
  열쇠는 이 PC 에만 윈도우 계정 암호화로 저장하고 화면·기록에 남기지 않습니다.
- **내 자료는 내 PC 에**: 모든 프로그램은 이 PC 안(127.0.0.1)에서만 듣습니다. 설정·대화 기억·열쇠는 이 PC 에만 저장합니다.
  바깥 두뇌(GPT·클로드 등)를 고르면 대화 글만 그 회사로 갑니다.

## 권장 사양

| | 최소 | 권장 |
|---|---|---|
| 운영체제 | 윈도우 10/11 64비트 | 윈도우 11 |
| 램 | 16GB | 32GB |
| 그래픽카드 | 없어도 됨(두뇌는 바깥 AI, 목소리는 윈도우 음성) | 엔비디아 그래픽 메모리 12GB 이상 |
| 디스크 | 약 10GB(그래픽카드 없음) | 약 25GB |

엔비디아 그래픽 메모리 6GB 이상이면 김비서 목소리(Qwen3-TTS)를, 그보다 작거나 없으면 윈도우 기본 음성을 씁니다. 김비서 목소리는 켤 때 그래픽 메모리가 3.3GB 이상 남아 있어야 그래픽카드로 켜고, 그보다 적으면(두뇌·다른 프로그램이 쓰는 중) 끊기는 대신 윈도우 음성으로 시작합니다. 쓰는 중에 그래픽 메모리가 모자라면 목소리가 끊기지 않고 윈도우 음성으로 저절로 바뀝니다.
마이크와 스피커(또는 헤드셋)가 필요합니다.

## 설치

1. [Releases](https://github.com/sinhs0301-prog/kimbiseo/releases/latest) 에서 내 그래픽카드에 맞는 설치 파일을 받습니다.
   엔비디아(RTX·GTX) → `KimBiseo-setup-<판>-NVIDIA.zip` · 라데온·인텔·내장 그래픽·그래픽카드 없음 → `KimBiseo-setup-<판>-Radeon.zip`
   (내 그래픽카드 확인: 작업 관리자 → 성능 → GPU)
2. zip 을 오른쪽 클릭 → 속성 → '차단 해제' 체크(있을 때만) → 압축 풀기.
3. 풀린 폴더의 `설치.bat` 을 두 번 누릅니다. 파란 경고창이 뜨면 '추가 정보' → '실행'.
4. 설치 창에서 '설치' 를 누르면 끝까지 저절로 합니다(빠른 인터넷에서 15~25분).
5. '김비서 켜기' 또는 바탕화면 '김비서' 아이콘. 처음 화면이 이름·호칭·두뇌·목소리·마이크를 차례로 물어봅니다.

파이썬·부품·모델은 설치할 때 공식 배포처(python.org · PyPI · PyTorch · GitHub · 허깅페이스)에서 내 PC 가 직접 받고,
받은 파일마다 sha256 을 확인합니다. 자세한 안내는 zip 안의 `설치방법.txt` 에 있습니다.

받다가 끊기면 받은 만큼에서 이어 받고, 안 되면 다른 방식(윈도우 내려받기)으로 다시 받습니다. '펫' 단계만 못 받았을 때는
설치를 끝내고 김비서(대화)부터 쓸 수 있으며, 펫은 설치 창의 '펫 다시 받기'·'직접 넣기'나 김비서 설정 → 펫 에서 나중에 넣을 수 있습니다.
설치 창에는 지난 시간과 지금 하는 일(받는 파일·받은 양·남은 시간)이 보이고, 3분 넘게 진전이 없으면 알려 줍니다.

지우기: 시작 메뉴 '김비서 제거' 또는 윈도우 설정 → 앱 → 김비서 → 제거(대화 기억·설정을 남길지 물어봅니다).

## 통역 쓰는 법

1. 말로 대화를 켜고(마이크 단추) **"태국어 통역해 줘"** 처럼 말합니다. 언어를 말하지 않고 **"통역해 줘"** 라고 하면 상대가 말한 언어를 알아서 알아듣습니다.
   대화 화면 아래 **통역** 단추를 눌러도 됩니다.
2. 내가 한국어로 말하면 상대 언어로, 상대가 말하면 한국어로 옮깁니다. 화면에는 번역이 크게, 원문이 작게 나오고,
   상대가 말한 외국 돈은 원화로 어림한 값(≈ 14,000원)이 한 줄 더 나옵니다(환율은 하루 한 번 받음 · 참고용 어림값).
3. 끝낼 때는 **"통역 그만"** 이라고 하거나 통역 칸의 **끄기** 를 누릅니다. 10분 동안 말이 없으면 저절로 꺼집니다(설정 → 통역에서 바꿈).
4. 외국어를 그 나라 목소리로 들으려면 **설정 → 통역 → '통역 목소리 받기'**(약 800MB, 한 번만)를 누릅니다. 0.1.16 까지 받아 둔 분은 한 번 더 누르면 태국어 목소리만 더 받습니다. 받지 않으면 외국어는 화면 글자로만 보여 줍니다.

- 통역 중 말은 **번역만** 합니다 — 상대가 "메모장 열어"라고 해도 김비서는 그 말을 번역할 뿐 실행하지 않습니다.
- 번역은 지금 쓰는 두뇌로 합니다(이 PC 의 Gemma 권장 — 대화가 PC 밖으로 안 나감 · 구독 두뇌는 한 마디마다 몇 초). 설정 → 통역의 '통역용 AI 주소'로 바꿀 수 있습니다.
- 통역 중에는 글로 친 말도 번역만 합니다(0.1.17~ · 명령은 실행 안 함, '통역 그만'은 받음).
- 통역한 말과 번역은 화면에만 보여 주고 기억·대화 기록에 남기지 않습니다.

| 언어 | 외국어 목소리 | 목소리 라이선스 |
|---|---|---|
| 영어 · 일본어 · 중국어 · 스페인어 · 프랑스어 · 이탈리아어 | Kokoro-82M (af_heart · jf_alpha · zf_xiaobei · ef_dora · ff_siwis · if_sara) | Apache-2.0 |
| 독일어 | Piper de_DE-thorsten-medium | 학습 자료 CC0 (Thorsten-Voice) |
| 그리스어 | Piper el_GR-rapunzelina-medium | 학습 자료 CC0 |
| 러시아어 | Piper ru_RU-denis-medium | 학습 자료 CC0 |
| 터키어 | Piper tr_TR-antalia-medium | CC-BY-4.0 — "tr_TR-antalia-medium" by ozgurguler |
| 태국어 (0.1.17~) | MrJMThaiTTS (Kokoro 태국어 판, thai_som) + FastThaiG2P | 가중치 Apache-2.0 · ★학습 자료가 비상업 모델의 합성음이라 상업 사용은 회색(THIRD_PARTY 참고) |
| 인도네시아어 · 베트남어 | 없음(글자만) | 상업용으로 쓸 수 있는 목소리(모델·학습 자료 둘 다)가 아직 없어서 — 나중에 더할 예정 |

읽기 프로그램 Piper(piper-tts, GPL-3.0)는 김비서와 따로 도는 프로그램으로, 사용자 PC 가 PyPI 에서 직접 받습니다. 통역 목소리는 모두 합성(기계) 목소리입니다.
자세한 고지 = [THIRD_PARTY_LICENSES](THIRD_PARTY_LICENSES/README.md).

## 폰으로 쓰기 (선택)

1. PC 김비서 **설정 → 폰 연결** 에서 '폰 연결 켜기'를 켜고 저장합니다. 윈도우 방화벽 창이 뜨면 **개인 네트워크**만 허용해 주세요.
2. 폰에 **김비서 앱**(릴리스 첨부 `KimBiseo-phone-0.1.4.apk` — 안드로이드 8.0 이상, 또는 `android/` 를 직접 만들기)을 깔고, PC 화면의 **'연결 코드 만들기'** 를 누릅니다.
   QR 과 8자리 숫자가 나옵니다(10분 동안, 한 번만).
   (폰 브라우저로 APK 를 받아 열면 '이 출처의 앱 설치 허용'을 한 번 켜라고 나옵니다. 플레이 스토어 앱이 아니라서 그렇습니다.)
3. 폰 앱에서 **QR 찍기**(또는 PC 주소·코드·인증서 확인 글자를 직접 넣기) → 폰에 나오는 '인증서 확인 글자'가 PC 화면과 같은지 보고 **연결하기**.
4. 폰 앱의 **대화 시작** 을 누르고 말하거나 글을 씁니다. 화면을 꺼도 대화가 이어집니다(알림에 '대화 중').

- 폰으로도 PC 일을 시킬 수 있습니다: 검색·사이트·프로그램 열기·김비서 메모 적기(설정 → 폰 연결 'PC 조작'으로 끔).
- 폰 쪽 일도 합니다: "엄마한테 전화해 줘"(전화 화면에 번호만 채움 — 통화 단추는 직접),
  "문자 보내 줘"(문자 화면에 받는 사람·내용만 채움 — 보내기는 직접), "유튜브 열어 줘".
- 길안내: "강남역 가는 길 안내해 줘", "티맵으로 서울역 안내해 줘". 앱 이름을 말하면 그 앱으로 열고, 말하지 않으면 폰에 깔린 앱 중 카카오맵 → 네이버지도 → 티맵 → 구글지도 → 카카오내비 순서로 고릅니다(없으면 웹 카카오맵).
  카카오맵·네이버지도·티맵은 목적지 검색 결과까지 열고 '길찾기'는 직접 누릅니다. 구글지도는 한국 안에서는 국내 자동차 길찾기가 없어 검색 결과로 열고('경로'는 직접), 해외에서는 바로 길안내를 시작합니다.
  카카오내비는 앱을 열고 목적지 이름을 복사해 두므로, 검색창에 붙여 넣어 주세요(목적지 바로 넘기기는 다음 판).
  고른 앱이 안 열리면(사용 중지 등) 다음 깔린 앱, 그다음 웹 카카오맵으로 엽니다.
- 지우기처럼 되돌리기 어려운 일은 폰 화면에 **'실행할까요?'** 를 묻고, '실행'을 눌러야 합니다(45초 안에 답이 없으면 안 함).
- 통역도 폰에서 씁니다(대화 화면 위 '통역').
- 한 번에 한 기기만 대화합니다 — 폰으로 대화를 시작하면 PC 창의 대화는 쉬고, 반대도 같습니다.
- 집 밖에서 쓰려면 폰과 PC 에 테일스케일을 깔고 같은 계정으로 로그인한 뒤 '테일스케일로도 연결 받기'를 켭니다.
  직접 넣을 때 PC 주소는 PC 화면에 나온 100.x.x.x 주소입니다(숫자 키패드에 쉼표를 눌러도 점으로 바로잡습니다).
- 연결이 안 되면 폰 앱이 까닭을 알려 줍니다: 코드가 다름 · 코드 시간(10분)이 지남 · 틀린 코드가 많아 잠깐 막힘 · PC 에 닿지 않음(와이파이·테일스케일 확인) ·
  PC 가 테일스케일 연결을 받지 않음. 틀린 코드를 넣어도 PC 화면의 코드는 그대로 쓸 수 있습니다(맞는 코드로 한 번 연결하면 그때 없어짐).

## 내 목소리 등록 (선택)

1. **설정 → 내 목소리** 에서 '확인 모델 받기'(약 40MB, 한 번만)를 누릅니다.
2. 나오는 문장을 하나씩 읽습니다(3개 이상, 5개 권장) → **등록 끝내기**.
3. **'등록한 목소리의 말만 명령으로 받기'** 를 켜고 저장합니다(엄격함: 느슨·보통·엄격). 폰 앱으로 말할 때도 같습니다.

- 다른 사람·TV 말은 듣고도 대답하지 않고, 대화 화면에 '안 들음'으로 보여 줍니다.
- 통역 중에는 상대 말은 그대로 번역하고, '통역 그만' 같은 켜기·끄기 말만 등록한 목소리일 때 받습니다.
- 저장하는 것은 목소리 특징(숫자 192개)뿐이고, 읽은 소리는 저장하지 않습니다. '등록 지우기'로 언제든 지웁니다.
- 폰 마이크로 말할 때는 PC 마이크보다 점수가 조금 낮게 나올 수 있습니다 — 잘 안 받으면 엄격함을 '느슨'으로.

## 업데이트

- 김비서를 켤 때(하루 한 번까지) 새 판이 있는지 봅니다. 설정 → 정보 → '업데이트 확인' 으로 바로 볼 수도 있습니다.
- 새 판이 있으면 대화 화면 위에 바뀐 점과 '업데이트 하기' 단추가 나옵니다.
- 누르면 받아서 **서명과 sha256 을 확인**한 뒤, 김비서를 잠깐 끄고 프로그램 코드만 바꾸고 다시 켭니다.
  대화 기억·설정·열쇠·목소리·펫 옷·모델은 그대로 둡니다.
- 새 판이 켜지지 않으면 **예전 판으로 저절로 되돌립니다**.
- 파이썬 부품이나 모델이 바뀌는 판은 새 설치 파일로 설치하라고 안내합니다(설치해도 대화 기억·설정은 남습니다).
