# KimBiseo（김비서）

自分の PC の中で動く**音声アシスタント**と**デスクトップキャラクターのペット**です。
「KimBiseo」と呼びかけるか、ウィンドウに入力すると答えてくれます。デスクトップのペットは話に合わせて口を動かし、表情や動きを変えます。
このプロジェクトは HighlifePC が制作しています。

## 主な機能

- **会話** — 声で質問し、声で答えを聞けます。天気・検索・価格調べ・計算・アプリの起動・記憶・メモなどの基本ツールを搭載。「RTX 5090 の価格を調べてメモにまとめて」のような複数手順の依頼も順番にこなします。
- **頭脳** — この PC で Claude Code や Codex（ChatGPT）に自分のアカウントでログインしていれば、そのサブスクリプションをそのまま使います（アカウントやトークンは KimBiseo からは見えません）。なければ、ローカルで動く Gemma 4（llama.cpp、配布元から直接ダウンロード）を使います。設定で OpenAI 互換のローカル AI や自分の API キー（GPT・Claude）にも切り替えられます。
- **耳と声** — 音声認識は whisper、声は Qwen3-TTS の KimBiseo ボイス（女性・男性の 2 種類、ペットの衣装に合わせて切り替え）。グラフィックメモリが足りないときは Windows 標準の音声を使います。0.1.17 以降の**音声ゲート**が、静かな部屋のノイズや息を「ありがとう」「こんにちは」と誤認識するのを防ぎます。
- **ペット** — デスクトップキャラクター（KimBiseo 女性・男性）。衣装パックはペットメニューの「衣装を追加」から選んでダウンロードできます。
- **口論（討論）モード**（0.1.18 以降）— 「口論しよう」「ディベートモード」と言うと、個人情報を抜きにして主張だけで他の AI とぶつかり合います。オンの間は、名前・住所・電話番号・記憶などの個人情報やメール・ファイル・PC 操作の道具を頭脳に渡さず、検索・天気・計算だけを使います。「口論やめて」「普通に戻って」で終了し、30 分話さないと自動で切れます。基本はタメ口・強い言葉・皮肉・挑発で、設定 → 会話の**成人向け口論（19+）**（PC 版）をオンにすると、本物の悪口・暴言・誇張した脅迫ジョーク・下ネタまで許可します。
- **通訳**（0.1.15 以降）— 「タイ語に通訳して」「通訳して」（自動判定）と言うと、韓国語と 13 言語（英語・タイ語・日本語・中国語・インドネシア語・ベトナム語・ドイツ語・ギリシャ語・トルコ語・ロシア語・フランス語・スペイン語・イタリア語）の間を通訳します。通訳中は相手の発言を**翻訳するだけ**で、命令としては実行しません。10 分間話さないと自動で切れます。外国語はネイティブ音声（設定 → 通訳 →「通訳音声をダウンロード」、約 800 MB）で読み上げ、インドネシア語・ベトナム語は文字表示のみです。
- **スマホから使う**（0.1.16 以降・任意・初期設定はオフ）— スマホアプリ「KimBiseo」をこの PC に接続すると、スマホに向かって話しても PC の KimBiseo が答えます。地図アプリの連携（カカオマップ・ネイバーマップ・T マップなど）とウォン換算の目安表示は**韓国のみ**の機能です。
- **自分の声を登録**（0.1.16 以降・任意・初期設定はオフ）— いくつかの文章を読むだけで、「登録した声の命令だけ聞き取る」をオンにできます（テレビや他の人の声に反応しなくなります）。
- **カスタマイズ**（設定）— 話し方（自動・丁寧・くだけた丁寧・タメ口）、回答の長さ、性格の説明、声の細かい設定、ペットの大きさ（50〜200%）、ウィンドウの大きさと位置の記憶。数字・日付・単位は画面の文字はそのままに、読み上げるときだけ韓国語にします（**韓国のみ**）。
- **データは PC の中に** — すべてのプログラムはこの PC の中（127.0.0.1）だけで待ち受け、設定・会話の記憶・キーはこの PC にのみ保存します。外部の頭脳（GPT・Claude など）を選んだときは、会話のテキストだけがその会社に送られます。

## 動作環境

Windows 10/11（64 ビット）、メモリ 16 GB 以上（推奨 32 GB）。NVIDIA のグラフィックメモリが 6 GB 以上あれば KimBiseo ボイスを使え、ない場合は Windows 標準の音声で動きます。マイクとスピーカー（またはヘッドセット）が必要です。

## インストール

1. [Releases](https://github.com/sinhs0301-prog/kimbiseo/releases/latest) から、グラフィックカードに合ったインストーラー（NVIDIA 用 / Radeon・Intel・内蔵用）をダウンロードします。
2. zip を展開し、中の `설치.bat` をダブルクリックします（青い警告が出たら「詳細情報」→「実行」）。
3. インストーラーの「インストール」を押すと最後まで自動で進みます（速い回線で 15〜25 分）。終わったら「KimBiseo を起動」を押します。
