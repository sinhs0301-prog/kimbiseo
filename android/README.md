# 김비서 폰 앱 (안드로이드)

내 폰으로 **내 PC 의 김비서**와 말·글로 대화하는 앱입니다. 서버 주소·열쇠는 앱에 들어 있지 않고,
PC 김비서 설정 → 폰 연결의 **QR(또는 주소 + 8자리 코드)** 로 연결할 때 받습니다.

- 연결하기: QR 찍기 또는 직접 넣기 → '인증서 확인 글자'가 PC 화면과 같은지 확인 → 연결하기
- 대화: 말(마이크 16kHz → PC, PC 목소리 24kHz → 폰)·글. 화면을 꺼도 이어짐(앞 서비스, 알림 '대화 중')
- 폰 일: 길안내(말한 앱, 없으면 깔린 순서 카카오맵 → 네이버지도 → 티맵 → 구글지도 → 카카오내비, 아무것도 없으면 웹 카카오맵. 카카오맵·네이버지도·티맵은 검색 결과까지, 구글지도는 한국 안이면 검색 결과·해외면 바로 길안내, 카카오내비는 앱을 열고 목적지 글 복사 — 붙여 넣기는 직접. 안 열리면 다음 앱 → 웹 카카오맵), 전화·문자 화면 채우기(걸기·보내기는 사용자가), 앱 열기
- '실행할까요?': PC 김비서가 되돌리기 어려운 일을 하기 전에 묻는 단추
- 통역: 켜기·끄기·언어 고르기·최근 번역
- 권한: 마이크·알림·카메라(QR)·연락처(이름으로 전화·문자 화면 열 때만). 통화 기록·직접 걸기·문자 발신 권한은 없음
- 폰 단독(PC 없이): 첫 화면에서 '폰에서 바로 쓰기'를 고르면 폰 안 AI 로 대화합니다. Gemma 4 E2B(LiteRT-LM) 모델을 처음 한 번 구글 공식 배포처(Hugging Face litert-community)에서 받아 앱 저장소에만 두고, 그 뒤엔 인터넷 없이 대화해요. 가입·계정·열쇠 없음.
  - 조건: 램 4GB 이상 · 안드로이드 8.0 이상 · 64비트 폰. 모델 2,588,147,712바이트 · sha256 `181938105e0eefd105961417e8da75903eacda102c4fce9ce90f50b97139a63c` · Apache License 2.0.
    램 4GB 폰은 조금 빠듯해 받기 화면에서 다른 앱을 닫으라고 안내하고, 램이 모자라 모델을 못 올리면 앱은 살아 있는 채로 까닭을 말한 뒤 PC 연결 모드로 돌아갈 수 있게 합니다.
  - 받기: 와이파이 기본, 크기·라이선스 동의, 이어받기, sha256 확인, 설정에서 지우기. 말하기는 폰의 기본 음성 인식, 읽기는 폰의 기본 TTS.
  - 대화 기록은 폰 안(앱 저장소)에만. 언어는 한국어·English·日本語·中文(폰 언어 또는 앱 설정).

## 만들기

    python build_apk.py --unit          # 규칙 단위 시험만
    python build_apk.py                 # APK (서명 안 됨 → 직접 apksigner 로 서명)

필요: JDK 17 이상, 안드로이드 SDK(platform 36 · build-tools 36), gradle 8.7~8.9(`--gradle` 또는 환경변수 `GRADLE`).
자기 열쇠로 서명하려면 환경변수 `KIMBISEO_KS_FILE`(절대 경로)·`KIMBISEO_KS_PASS`·`KIMBISEO_KS_ALIAS` 를 넣고 만듭니다.
`--test` 는 시험판(adb 로 연결하기·소리 넣기 — `MainActivity.testHooks`)이라 배포하면 안 됩니다.

## 파일

| 파일 | 하는 일 |
|---|---|
| `Pairing.kt` | QR 읽기·주소·지문 규칙(순수 규칙, 단위 시험) |
| `Net.kt` | 인증서 지문 고정 HTTPS·WSS, 연결하기 |
| `Store.kt` | 연결 정보(기기 토큰은 안드로이드 키 저장소로 암호화) |
| `TalkService.kt` | 대화 연결·소리·PC 사건 처리 |
| `Doer.kt` · `Rules.kt` | 폰 일(길안내·전화·문자·앱 열기)과 그 규칙 |
| `MainActivity.kt` · `Ui.kt` | 화면(첫 화면·연결하기·대화·통역·설정·실행할까요?) |
| `SoloActivity.kt` | 폰 단독 화면(모델 받기·대화·설정) |
| `SoloBrain.kt` | 폰 안 AI(LiteRT-LM) 실행·흘려 보내기·지시문 |
| `SoloModel.kt` · `SoloDownload.kt` | 모델 정보·기기 확인·이어받기·sha256 |
| `SoloAction.kt` · `SoloHistory.kt` | 대답의 PHONE 줄 해석·폰 안 대화 기록 |
| `Lang.kt` | 앱 언어(ko/en/ja/zh) 고정·받아쓰기/목소리 언어 |
