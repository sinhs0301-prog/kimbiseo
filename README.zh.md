# KimBiseo（김비서）

一款在你自己电脑上运行的**语音助手**和**桌面角色宠物**。
喊一声“KimBiseo”或在窗口里打字，它就会回答；桌面上的宠物会跟着说话动嘴，还会变换表情和动作。
本项目由 HighlifePC 制作。

## 主要功能

- **对话** — 用嘴问、用耳听。内置天气、搜索、比价、计算、打开程序、记住事情、记笔记等基本工具，像“查一下 RTX 5090 的价格并整理到记事本里”这样的多步请求也会依次完成。
- **大脑** — 如果这台电脑上已用你自己的账号登录了 Claude Code 或 Codex（ChatGPT），就直接使用该订阅（它只调用程序，看不到你的账号和令牌）。没有的话，就在本地运行 Gemma 4（llama.cpp，从原发布方直接下载）。也可以在设置里换成 OpenAI 兼容的本地 AI 或自己的 API 密钥（GPT、Claude）。
- **耳朵和声音** — 语音识别用 whisper，说话用 Qwen3-TTS 的 KimBiseo 声音（女声、男声两种，会跟随宠物服装切换）。显卡显存不足时使用 Windows 自带语音。0.1.17 起的**声音门**可以防止把安静房间里的噪音和呼吸声误认成“谢谢”“你好”。
- **宠物** — 桌面角色（KimBiseo 女、KimBiseo 男）。服装包可在宠物菜单的“获取更多服装”里按需下载。
- **翻译**（0.1.15 起）— 说“翻译成泰语”或“翻译”（自动识别），即可在韩语和 13 种语言（英语、泰语、日语、中文、印尼语、越南语、德语、希腊语、土耳其语、俄语、法语、西班牙语、意大利语）之间互译。翻译时对方说的话**只做翻译**，不会当作命令执行；10 分钟没说话会自动关闭。外语用母语者声音朗读（设置 → 翻译 →“下载翻译声音”，约 800 MB），印尼语和越南语仅显示文字。
- **用手机使用**（0.1.16 起，可选，默认关闭）— 在手机上安装“KimBiseo”应用并连接到这台电脑后，对着手机说话也会由电脑上的 KimBiseo 回答。地图应用联动（KakaoMap、Naver Map、T Map 等）和韩元换算提示是**韩国专用**功能。
- **登记自己的声音**（0.1.16 起，可选，默认关闭）— 读几段句子后，可以开启“只听从已登记的声音”（不再回应电视或别人的声音）。
- **随心调整**（设置）— 语气（自动、敬语、轻松敬语、平语）、回答长度、性格描述、声音细节、宠物大小（50~200%）、窗口大小和位置记忆。数字、日期、单位只在朗读时转成韩语，屏幕文字保持不变（**韩国专用**）。
- **数据留在本机** — 所有程序只在这台电脑上（127.0.0.1）监听，设置、对话记忆和密钥只保存在本机。选择外部大脑（GPT、Claude 等）时，只有对话文本会发送到那家公司。

## 系统要求

Windows 10/11（64 位），内存 16 GB 以上（建议 32 GB）。NVIDIA 显存 6 GB 以上可使用 KimBiseo 声音，否则使用 Windows 自带语音。需要麦克风和扬声器（或耳机）。

## 安装

1. 从 [Releases](https://github.com/sinhs0301-prog/kimbiseo/releases/latest) 下载与你的显卡匹配的安装包（NVIDIA 版 / Radeon、Intel、核显版）。
2. 解压 zip，双击其中的 `설치.bat`（若出现蓝色警告，点“更多信息”→“仍要运行”）。
3. 在安装窗口点“安装”，之后会自动完成（网速快时约 15~25 分钟），结束后点“启动 KimBiseo”。
